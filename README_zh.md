# FormSaver - Chrome 插件

FormSaver 是一款 Chrome 浏览器扩展程序，允许用户根据网页 URL 保存和恢复表单数据。这在填写需要多次提交的表单，或者表单因某些原因被拒绝需要更正后重新提交时特别有用。

## 功能特色

- **保存表单数据**: 在有表单的页面上右键单击，即可保存所有表单字段值
- **恢复表单数据**: 根据相同的 URL 恢复之前保存的表单数据
- **弹窗界面**: 简洁的弹窗界面，可手动保存/恢复表单数据
- **自动字段检测**: 自动检测并保存输入框、文本域和选择框元素
- **基于 URL 的存储**: 将表单数据与捕获时的特定 URL 关联

## 安装方法

1. 克隆或下载此仓库
2. 打开 Chrome 浏览器并导航到 `chrome://extensions`
3. 在右上角启用"开发者模式"
4. 点击"加载已解压的扩展程序"，选择包含扩展文件的目录
5. FormSaver 图标现在应该出现在 Chrome 工具栏中

## 使用方法

### 方法 1：右键上下文菜单（推荐）

1. 导航到您要保存的带有表单的网页
2. 按需填写表单字段
3. 在页面任意位置右键单击
4. 从上下文菜单中选择"保存当前表单数据"
5. 表单数据现已保存并与当前 URL 关联

恢复表单数据：
1. 返回到保存表单时的相同 URL
2. 在页面任意位置右键单击
3. 从上下文菜单中选择"恢复已保存的表单数据"
4. 表单字段将自动填充已保存的值

### 方法 2：弹窗界面

1. 单击 Chrome 工具栏中的 FormSaver 图标
2. 单击"保存当前表单"以保存当前表单数据
3. 单击"恢复已保存表单"以使用保存的数据填充页面

## 技术详情

### 文件结构

- `manifest.json`: Chrome 扩展配置文件
- `src/background.ts`: 处理表单数据存储和上下文菜单
- `src/content.ts`: 在网页上运行以与表单交互
- `src/contextMenu.ts`: 管理右键上下文菜单功能
- `popup/popup.html`: 扩展弹窗的 HTML
- `popup/popup.js`: 弹窗界面的 JavaScript
- `assets/`: 包含扩展图标

### 权限

- `storage`: 用于本地存储表单数据
- `activeTab`: 访问当前标签页
- `contextMenus`: 添加右键菜单选项
- `<all_urls>`: 访问所有网站上的表单数据

### 支持的表单元素

- 文本输入框 (`<input type="text">`)
- 密码输入框出于安全原因被排除
- 复选框 (`<input type="checkbox">`)
- 单选按钮 (`<input type="radio">`)
- 文本域 (`<textarea>`)
- 选择下拉框 (`<select>`)

## 开发

要为此扩展做贡献：

1. 安装依赖项: `npm install`
2. 构建项目: `npm run build`
3. 开发模式: `npm run dev`（监视更改并自动重建）

## 安全性

- FormSaver 不会向外部服务器传输任何数据
- 所有数据均存储在您的浏览器本地
- 密码字段故意从保存的数据中排除以确保安全
